A collection of AI agent skills built for **Claude Code**, **Antigravity**, **OpenCode**, **Cline**, or any skill-supported autonomous agent.

These skills extend your agent's capabilities with specialized tools and workflows, from security auditing to code generation.

You can add skills to your agent using the `npx skills` command.

**Installation:**

```bash
npx skills add https://github.com/shantoislamdev/Skills --skill <skill-name>
```

---

# Skills:

### ideator

Generate distinctive, highly original, and unconventional ideas, concepts, or solutions. Use this skill when the user asks for brainstorming, business concepts, automation workflows, creative writing, or problem-solving. Generates provocative, paradigm-shifting, and deeply specific concepts that strictly avoid generic, surface-level "AI slop" listicles.

**Installation:**

```bash
npx skills add https://github.com/shantoislamdev/Skills --skill ideator
```
